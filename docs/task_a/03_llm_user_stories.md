## Roles

| Role | Description |
|---|---|
| Guest customer | Anyone using the machine without logging in. |
| Registered user | Customer with an account, profile and history. |
| Privacy-conscious customer | Customer who cares how camera and personal data are used. |
| Technician | Maintenance staff using the admin mode. |
| Operator | Company/office that owns the machine and its revenue. |
